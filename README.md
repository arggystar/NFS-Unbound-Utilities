**Step 2: The First Launch**
Double-click the `VelocityArbitrage.exe` file. The system will perform a quick **system audit** to ensure optimal compatibility. It will then ask you to point it to your game installation directory. It can usually auto-detect this, but manual selection is supported for custom installs.

**Step 3: The Calibration Run**
We highly recommend performing a "Calibration Run" before your first serious race. This involves driving in a straight line for 3 seconds and then executing a hard 90-degree turn. **Step 4: Explore the Cockpit**
Once calibration is complete, access the main dashboard via the `F2` key (default). Here you can toggle modules, load community presets, and configure your HUD layout.
